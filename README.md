# HITS
Hygiene Issue and Tracking System

HITS is a full-stack sanitation monitoring platform for reporting, translating, tracking, and managing hygiene issues. It includes a React dashboard, an Express API, MongoDB storage, WhatsApp integration, Cloudinary image uploads, and bilingual support.
Features
Worker registration and management
Sanitation block management
Photo-based hygiene issue reports
Duplicate report detection
English and Telugu support
WhatsApp webhook integration
Dashboard for viewing report status
Cloudinary image storage
Light and dark themes
Vercel deployment support
